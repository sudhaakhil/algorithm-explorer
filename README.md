# Algorithm Explorer — Coin Change

A beginner-friendly interactive website comparing four approaches to the coin-change problem: brute force, greedy, dynamic programming, and backtracking.

## How to use
Open `index.html` in a browser. Enter a positive amount, choose a coin set, and select an algorithm to view the coins used, steps, and complexity.

## Deploy with GitHub Pages
In repository **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, and save. The public site will appear at `https://sudhaakhil.github.io/algorithm-explorer/` after deployment.

## Important note
For arbitrary denominations, greedy is not always optimal. Brute force and backtracking may be expensive for large amounts; this demo limits inputs to keep the browser responsive.
